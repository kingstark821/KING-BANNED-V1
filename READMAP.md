## 🛠️ Installation
1. Ouvrir Termux.
2. `pkg update && pkg upgrade`
3. `pkg install python`
4. `pip install -r requirements.txt`

## 👑 Comment l'utiliser
1. Lancer le script: `python main.py`
2. Entrer le numéro cible (format international).
3. Définir la quantité de "Signals" (nombre de tentatives).
